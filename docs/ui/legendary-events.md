# Legendäre Events

Vorbereitet am 20.10.2026, noch nicht veröffentlicht.

- Eventübersicht und Eventprojekt verwenden die vorhandene legendäre Palette (Goldfläche/legendärer Rand und Text) und „LEGENDÄR“ statt „EPISCH“.
- Englische Beschriftungen: LEGENDARY / LEGENDARY · EVENT. Empfehlungsaufträge behalten ihre epische Seltenheit und Farbe.
- Eventkatalog liefert `legendary`; gespeicherte Status-/Fortschrittsdaten bleiben erhalten. Veraltete Seltenheitsangaben im gespeicherten Event überschreiben den aktuellen Katalog nicht.
- Bestehende Eventtest-Erwartung angepasst. Eventansicht mit verfügbarem, laufendem und beendetem Zustand sowie alten Metadaten direkt geprüft; keine Zustandsmutation. Kein vollständiger App-Build oder Gerätetest für diesen vorbereiteten Stand.
