# Weathered green buttons

Interactive petrol controls use a slightly stronger, matte patina with irregular dark green areas and muted worn olive edges. Paper controls and noninteractive surfaces keep their existing materials. The Vertrieb pilot button uses the same shared button variant.

The 512 px bundled JPEG replaces the existing texture for these controls; it adds no additional image layer, animation, blur, network request or layout measurement. The texture subtree remains memoized with scalar props. Button sizes, touch areas, labels, disabled and pressed states are unchanged.

The texture was generated with the built-in ImageGen tool; its exact prompt and optimization are stored beside the asset. Asset appearance was inspected. Native device visual validation was not available.
