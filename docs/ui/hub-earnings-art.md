# Stadthub-Ertragsbild

Der kompakte Kopf der Ertragskarte zeigt einen historischen Verladehof mit Kontor, beladenen Karren und kleinem Kran. Das Bild ersetzt Überschrift/Schatzkistenicon und große Einzelmünze, statt einen weiteren Bildabschnitt hinzuzufügen. Der Kopf ist 124 dp hoch und läuft bis zum bestehenden Kartenrahmen.

Der Kassenfüllstand liegt oben rechts auf dunkler transparenter Fläche. Titel und tatsächlicher Münzbetrag stehen unten auf einem gemeinsamen kontrastreichen Band; große Beträge passen sich einzeilig an. Alle Texte bleiben technische UI. Das Bild selbst ist dekorativ und enthält keine Beschriftung. Zeitstrahl, Status und expliziter Sammelbutton bleiben unverändert auf Pergament.

Produktionsbild: `assets/art/hub/earnings-yard.jpg`; Prompt im benachbarten JSON. Keine Änderung an Hub-Mechanik oder Belohnungen.
