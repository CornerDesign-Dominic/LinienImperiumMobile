# Transportkarten

Die Sammlung heißt in Navigation, Auswahlfenstern, Itemnamen, Belohnungen und Spielhilfe einheitlich „Transportkarten“ beziehungsweise „Transportkarte“. Interne Komponenten, Karten-IDs und gespeicherte Daten bleiben unverändert; Texte der unveränderten Web-Basis werden an der mobilen Darstellung normalisiert.

Der Hauptmenüeintrag trägt den Untertext „Sammeln und verbessern“. Rechts steht der Besitzstand `x / xx`: Gezählt werden unterschiedliche freigeschaltete Karten aus dem aktuellen Katalog, unabhängig von Stufe, Duplikaten oder Splittern. Die Gesamtzahl wird nicht fest auf 25 gesetzt. Screenreader lesen zusätzlich „Karten gesammelt“.
